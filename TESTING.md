# Закрытое тестирование на VPS

Автор установщика: **Илья Рублев**.

[Telegram](https://t.me/Rublev_YouTube) · [YouTube](https://www.youtube.com/@Ilya_Rublev) · [Boosty](https://boosty.to/rublev13)

Этот порядок предназначен для проверки перед публичным выпуском. Сквозной тест пока не проведён. Для зарубежного выхода используйте отдельный зарубежный VPS с Ubuntu 22.04/24.04 или Debian 12/13, архитектурой amd64/arm64 и systemd.

## 1. Перенести установщик

Откройте [openflux-install.sh](openflux-install.sh) в GitHub под аккаунтом с доступом к закрытому репозиторию. Нажмите **Download raw file** в панели файла. Сохраните именно файл `.sh`, а не HTML-страницу GitHub.

Откройте SFTP-соединение с VPS в вашем SSH-клиенте и загрузите файл в домашний каталог пользователя, под которым подключаетесь. Для `root` это обычно `/root`. Токен GitHub для этого способа не нужен.

В SSH-терминале выполните:

```bash
cd ~
bash -n openflux-install.sh
bash openflux-install.sh --help
```

Эти команды не устанавливают OpenFlux. Если проверка синтаксиса завершилась с ошибкой, не продолжайте установку.

## 2. Установить

Создайте отдельный пустой документ Яндекса. Включите редактирование по ссылке и проверьте его в режиме инкогнито без входа в аккаунт. Нужна ссылка вида `https://disk.yandex.ru/i/ИДЕНТИФИКАТОР`.

Под `root` запустите:

```bash
bash openflux-install.sh
```

Под обычным пользователем с административными правами:

```bash
sudo bash openflux-install.sh
```

Выберите пункт **1**, вставьте ссылку и дождитесь результата. Если редактор не определился, проверьте доступ к документу и выберите редактор вручную либо отмените установку.

## 3. Подключить клиент

Для Android установите [OpenFlux-Android v1.1.1](https://github.com/damnurmum/OpenFlux-Android/releases/tag/v1.1.1). В разделе «Профили» нажмите кнопку QR, отсканируйте код, сохраните профиль и подключитесь. При использовании VPN-режима подтвердите запрос Android. Для повторного показа кода на сервере:

```bash
sudo openflux-setup --qr
```

В браузере телефона с подключённым клиентом откройте [api.ipify.org](https://api.ipify.org). Для сравнения на VPS выполните:

```bash
curl -4 --connect-timeout 15 --max-time 30 https://api.ipify.org
```

Проверьте, что соединение клиента проходит через ожидаемый выход VPS. Для iPhone совместимость этого профиля пока не подтверждена. Настройка Windows описана в [README.md](README.md).

QR-код, ссылка подключения, клиентский архив и рабочая ссылка на документ содержат доступ к тестовой установке. Не помещайте их в Git и отчёт о тестировании.

## 4. Проверить управление

На тестовом VPS последовательно проверьте:

1. Состояние: `sudo openflux-setup --status`.
2. Повторный вывод профиля: `sudo openflux-setup --qr`.
3. Перенастройку с прежним документом: `sudo openflux-setup --install`. Прежний клиентский профиль должен продолжить работать, поскольку ключ сохраняется.
4. Перезагрузку: `sudo reboot`. Соединение SSH закроется; после повторного входа проверьте состояние службы и подключение клиента.
5. Удаление: `sudo openflux-setup --uninstall`, затем введите `УДАЛИТЬ`. Выполняйте этот шаг после проверки соединения: он удаляет ключ и настройки.
6. Повторную установку из сохранённого файла. Импортируйте новый QR, поскольку после удаления создаётся новый ключ.

Статус службы `active` подтверждает только запуск процесса. Отдельно проверьте фактическую передачу трафика и внешний адрес.
